Agent Login directory

Trusted providers

Draft programme. No approved providers.

The programme is not operational. Its published draft does not enable sign-in through any provider.

A shared policy that websites can choose

When operational, websites can explicitly choose this policy to receive reviewed provider additions, suspensions and removals. The website still controls agent permissions and its own sessions. Using Agent Login does not automatically subscribe a website.

SentFrom.ai and AgentID are directory candidates, not approved providers. A directory listing or a passing test suite does not establish programme admission.

Read the draft programme and admission criteria or review the publication and activation requirements.

Historical draft feed

The machine-readable draft retains its original dates and exact bytes. Rebuilding this page never renews it. An expired or inactive feed refuses new sign-ins; it does not fall back to directory candidates.
